Layer 01 · Security
Helmet
npm: helmet@7 · ~4.2ms
First
Sets ~15 HTTP security headers to protect against common web vulnerabilities like XSS, clickjacking, and MIME-sniffing.
Content-Security-Policy X-Frame-Options: DENY HSTS X-Content-Type-Options Referrer-Policy 
import helmet from 'helmet';
// Applied globally — must be first middleware
app.use(helmet({
  contentSecurityPolicy: {
    directives: {
      defaultSrc: ["'self'"],
      scriptSrc:  ["'self'", "'nonce-{nonce}'"],
    }
  },
  hsts: { maxAge: 31536000, includeSubDomains: true },
  frameguard: { action: 'deny' },
}));

Layer 02 · Access
CORS
npm: cors@2 · ~1.1ms
Gatekeeper
Enforces Cross-Origin Resource Sharing policy. Whitelists allowed origins, methods and headers. Pre-flight OPTIONS requests are handled automatically.
Origin whitelist Credentials: true OPTIONS preflight Exposed headers 
import cors from 'cors';

const ALLOWED = [
  'https://furnistorm.in',
  'https://admin.furnistorm.in',
];

app.use(cors({
  origin: (origin, cb) =>
    ALLOWED.includes(origin) ? cb(null, true)
    : cb(new Error('Origin not allowed')),
  methods: ['GET','POST','PUT','PATCH','DELETE'],
  credentials: true,
  maxAge: 86400,
}));

Layer 03 · Throttle
Rate Limiting
npm: express-rate-limit@7 · ~0.8ms
100 req/min
Prevents brute-force and DDoS attacks by capping requests per IP. Separate stricter limits on auth routes. Returns 429 on breach with Retry-After header.
100 req / 60s Auth: 10 req / 15min Redis store X-RateLimit-* headers 429 Too Many Requests 
import rateLimit from 'express-rate-limit';
import RedisStore  from 'rate-limit-redis';

const limiter = rateLimit({
  windowMs: 60_000,   // 1 minute
  max:      100,
  standardHeaders: true,
  legacyHeaders:   false,
  store: new RedisStore({ client: redis }),
  message: { error: 'Too many requests' },
});
app.use('/api', limiter);

Layer 04 · Input
Validation
npm: zod@3 + express-zod-api · ~2.4ms
Schema
Validates request body, query params and route parameters against Zod schemas. Returns structured 400 error with field-level details before business logic executes.
Body schema Query params Route params 400 + field errors TypeScript inference 
import { z } from 'zod';

const ProductQuerySchema = z.object({
  limit:    z.coerce.number().min(1).max(100).default(20),
  category: z.enum(['sofa','chair','table']).optional(),
  minPrice: z.coerce.number().nonnegative().optional(),
});

const validate = (schema) => (req, res, next) => {
  const result = schema.safeParse(req.query);
  if (!result.success)
    return next(new ValidationError(result.error));
  req.validatedQuery = result.data;
  next();
};

Layer 05 · Safety Net
Central Error Handler
Custom 4-arg Express middleware · ~0.3ms
Global
Single error funnel registered last. Classifies errors by type (Validation, Auth, NotFound, DB, Unknown), maps to correct HTTP status, and masks stack traces in production.
Error classification HTTP status mapping Prod stack masking Correlation ID RFC 7807 format 
// Must be registered AFTER all routes
app.use((err, req, res, next) => {
  const status = err.statusCode ?? 500;
  const isProd = process.env.NODE_ENV === 'production';

  logger.error({ err, correlationId: req.id });

  res.status(status).json({
    type:     err.type   ?? 'INTERNAL_ERROR',
    title:    err.message ?? 'Something went wrong',
    status,
    detail:   isProd ? undefined : err.stack,
    instance: req.originalUrl,
    correlationId: req.id,
  });
});

Layer 06 · Docs
Swagger / OpenAPI
npm: swagger-jsdoc + swagger-ui-express · ~12ms cold
OAS 3.1
Auto-generates OpenAPI 3.1 spec from JSDoc annotations. Serves interactive Swagger UI at /api/docs. Disabled in production via env flag.
OAS 3.1 spec JSDoc annotations /api/docs UI Bearer auth scheme Disabled in prod 
import swaggerJsdoc  from 'swagger-jsdoc';
import swaggerUi     from 'swagger-ui-express';

const spec = swaggerJsdoc({
  definition: {
    openapi: '3.1.0',
    info: { title: 'FURNISTORM API', version: '1.0.0' },
    components: { securitySchemes: {
      bearerAuth: { type: 'http', scheme: 'bearer' }
    }}
  },
  apis: ['./src/routes/**/*.ts'],
});

if (process.env.NODE_ENV !== 'production')
  app.use('/api/docs', swaggerUi.serve, swaggerUi.setup(spec));

Layer 07 · Observability
Logging
npm: pino@8 + pino-http · ~0.5ms
JSON logs
Structured JSON logging via Pino (fastest Node logger). Logs every request with correlation ID, response time, status code, user agent. Streams to stdout → forwarded to Loki.
Pino JSON output Correlation ID Response time (ms) Log levels Loki / Grafana 
import pino     from 'pino';
import pinoHttp from 'pino-http';

export const logger = pino({
  level: process.env.LOG_LEVEL ?? 'info',
  transport: process.env.NODE_ENV !== 'production'
    ? { target: 'pino-pretty' } : undefined,
});

app.use(pinoHttp({
  logger,
  genReqId: (req) => req.headers['x-correlation-id'] ?? randomUUID(),
  customSuccessMessage: (req, res) =>
    `${req.method} ${req.url} → ${res.statusCode}`,
}));
